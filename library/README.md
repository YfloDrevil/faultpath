## Safety rules
- Never show an unverified torque, pressure, voltage, pin, connector position, or test-port location as a confirmed specification.
- Never infer wiring from wire colour alone.
- Require exact machine/vehicle, model, year, engine, configuration and manual revision before applying OEM specs.
- High-voltage systems, stored hydraulic energy, suspended loads, air-brake systems, fire suppression and moving machinery require isolation/competent personnel.
- Quarantine inaccurate illustrations until reviewed against primary source drawings.
- Preserve provenance: source title, file ID/URL, page/figure, model applicability, verification status.
- Do not republish copyrighted manuals without permission. Store source pointers and original diagnostic commentary instead.
